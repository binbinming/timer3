# 时间工具 - 计时器、闹钟、秒表三合一应用

这是一个简洁高效的时间管理工具，集成了计时器、闹钟和秒表三大功能，帮助用户更好地管理和利用时间。

## 主要功能

### 计时器
- 预设模板：针对不同场景（学习、运动、休闲等）的计时模板
- 自定义设置：可自由设置时间、名称和分类
- 视觉反馈：圆形进度条直观显示剩余时间
- 通知提醒：计时结束后发出声音和系统通知

### 闹钟
- 灵活设置：可选择重复的日期（按周几）
- 多闹钟支持：可同时设置多个闹钟
- 一键开关：便捷切换闹钟启用状态
- 自定义标签：为每个闹钟添加个性化名称

### 秒表
- 高精度计时：精确到百分之一秒
- 计次功能：支持记录和显示每次计时
- 简洁界面：大字体显示，操作按钮易于点击

## 使用指南

### 计时器使用
1. 点击底部导航栏的"计时器"进入计时器界面
2. 选择预设模板或点击右下角"+"按钮创建自定义计时器
3. 点击"启动"或"使用"按钮开始计时
4. 计时过程中可暂停、继续或重置计时器

### 闹钟使用
1. 点击底部导航栏的"闹钟"进入闹钟界面
2. 查看已设置的闹钟，可通过开关按钮启用或禁用
3. 点击右下角"+"按钮添加新闹钟
4. 设置闹钟名称、时间和重复日期

### 秒表使用
1. 点击底部导航栏的"秒表"进入秒表界面
2. 点击中间按钮开始计时
3. 计时过程中可点击右侧按钮记录分段时间
4. 点击左侧按钮重置秒表
